# Примеры данных

Здесь лежат **обезличенные** примеры рабочих файлов конвейера. Настоящие файлы
(очередь тем, факт-база, каталог ссылок, реестр публикаций) в репозиторий не
попадают — они в `.gitignore`, потому что содержат данные конкретного сайта.

| Пример | Куда положить | Что это |
| --- | --- | --- |
| `themes.example.txt` | `data/themes.txt` | очередь тем: одна тема на строку |
| `facts.example.json` | `data/facts.json` | факт-база компании — единственный разрешённый источник цифр |
| `article.example.json` | — | форма ответа писателя: что именно возвращает LLM и принимает валидатор |

`data/internal_links.json`, `data/catalog.json` и `data/registry.json` не
копируйте: их собирает `python src/catalog.py` по вашему сайту (через
`publisher.php?action=inspect`), а `registry.json` наполняется публикациями.

Пошаговый старт — в разделе «Quick start» файла `README.md`.
